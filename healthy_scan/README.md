# Healthy Scan

A comprehensive Flutter mobile application for health and nutrition tracking. Scan food products, track your diet, and monitor your health metrics.

## Features

- **Barcode Scanning**: Scan food product barcodes to get detailed nutritional information
- **Food Diary**: Log and track meals and snacks through the day
- **Nutrition Tracking**: Monitor your daily calorie intake and macronutrient balance
- **Profile Management**: Set health goals, preferences, and dietary restrictions
- **Visual Analytics**: View your nutrition data with intuitive charts and graphs

## Getting Started

### Prerequisites

- Flutter (2.5.0 or higher)
- Dart (2.14.0 or higher)
- Android Studio or VS Code with Flutter extensions

### Installation

1. Clone the repository
```
git clone https://github.com/yourusername/healthy_scan.git
```

2. Navigate to the project directory
```
cd healthy_scan
```

3. Install dependencies
```
flutter pub get
```

4. Run the application
```
flutter run
```
